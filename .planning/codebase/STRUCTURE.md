## Directory Purposes

**`app/routes/`:**
- Purpose: File-based routes using `@react-router/fs-routes`
- Contains: Page components (`.tsx`), API endpoints (`.ts`)
- Key files: `_index.tsx`, `$project.sessions._index.tsx`, `$project.sessions.$sessionId.tsx`, `kanban.tsx`
- Naming: `$` = dynamic segment, `.` = nesting, `_index` = index route, `api.*` = API routes
- All page components export `loader()`, `action()`, `meta()` functions

**`app/components/`:**
- Purpose: Reusable React UI components (not page-level)
- Contains: React components with hooks
- Key files: `KanbanBoard.tsx`, `StoryCard.tsx`, `KanbanColumn.tsx`, `MessageTypeIcon.tsx`, `CancelButton.tsx`, `MobileNav.tsx`, `DesktopNav.tsx`
- Pattern: Functional components, props-based interface, no loaders/actions

**`app/types/`:**
- Purpose: Shared TypeScript interfaces & type definitions
- Contains: Domain types (KanbanStory, KanbanState, etc.)
- Key files: `kanban.ts` (primary, exports KanbanStatus, KanbanStory, etc.)

**`app/utils/`:**
- Purpose: Shared utility functions (client + server)
- Contains: Format functions, path safety, file tailing, kanban state management
- Key files:
  - `format.ts` - Cost formatting (USD, color gradients)
  - `path-safety.server.ts` - Path validation for file system access (server-only)
  - `kanban.server.ts` - Kanban state I/O and mutations (server-only)
  - `kanban.ts` - Client-side kanban utilities
  - `file-tail.server.ts` - Real-time file monitoring (server-only)
- Note: `.server.ts` suffix = server-only, excluded from browser bundle

**`app/welcome/`:**
- Purpose: Shared layout + static components
- Contains: Logo SVGs, reusable UI elements
- Key files: `welcome.tsx`, `FileViewer.tsx`

**`app/__tests__/`:**
- Purpose: Unit tests (Vitest)
- Contains: Tests for routes, utilities, components
- Pattern: Co-located tests (one test file per module)

**`build/`:**
- Purpose: Compiled output (generated, not committed)
- Contains: `build/server/index.js` (SSR server), `build/client/**` (browser assets)
- Generated by: `pnpm build` (React Router build)

**`e2e/`:**
- Purpose: Playwright E2E tests
- Contains: Browser automation tests, fixtures

**`public/`:**
- Purpose: Static assets served at root
- Contains: Favicons, static files

**`.planning/codebase/`:**
- Purpose: Codebase analysis & documentation
- Contains: ARCHITECTURE.md, STRUCTURE.md, CONVENTIONS.md, etc.

**`plans/`:**
- Purpose: Implementation plans created during development
- Contains: Timestamped markdown files (YYYY-MM-DD-HH-MMam-pm-*.md)

## Naming Conventions

**Files:**
- Routes: `_index.tsx` (index), `$param.tsx` (dynamic), `api.*.ts` (API endpoints)
- Server-only: `*.server.ts` suffix
- Components: PascalCase, e.g., `KanbanBoard.tsx`
- Utilities: camelCase, e.g., `formatUSD()`
- Types: PascalCase exported interfaces, e.g., `KanbanStory`

**Directories:**
- Feature directories: lowercase + hyphens (e.g., `app/routes`, `app/components`)
- No underscores except for React Router special files (`.server`, `_index`)

**Exports:**
- Named exports preferred (e.g., `export function getProjects()`)
- Default exports for route components only (React Router requirement)
- Re-exports via barrel files: `index.ts` in component directories (if needed)

**Imports:**
- Path alias `~` = `app/` directory
- Example: `import { KanbanBoard } from "~/components/KanbanBoard"`
- Server imports: Dynamic via `await import()` in loaders/actions only (SSR safety)

## Where to Add New Code

**New Feature (e.g., filtering, search):**
- Primary code: `app/routes/kanban.tsx` or relevant route file
- Components: `app/components/` for reusable UI parts
- Tests: `app/__tests__/` with matching filename (e.g., `KanbanBoard.test.tsx`)
- Types: Add to `app/types/kanban.ts` if kanban-related, else inline

**New Component/Module:**
- Implementation: `app/components/` for UI, `app/utils/` for logic
- Server-only logic: `app/utils/filename.server.ts`
- Export: Named export with JSDoc comments
- Test: Co-located test file (e.g., `MyComponent.test.tsx`)

**New Route:**
- Create file in `app/routes/` following naming: `path.to.route.tsx`
- Example: `app/routes/admin.users._index.tsx` → `/admin/users`
- Required exports: `meta()`, `loader()` (if data needed), `action()` (if mutations)
- Import server modules dynamically in loader/action only

**New Utility:**
- If shared: `app/utils/filename.ts` (client) or `filename.server.ts` (server-only)
- If specific to one route: Consider inline, or `app/utils/` if reusable
- Export as named functions or object with methods
- Add JSDoc for public functions

**New Type:**
- If part of kanban domain: Add to `app/types/kanban.ts`
- If route-specific: Define inline in route file after imports
- If widely used: Consider adding to `app/types/kanban.ts` as well

## Special Directories

**`.react-router/`:**
- Purpose: Generated types for React Router routes
- Generated: By `pnpm typecheck` command
- Committed: No (in .gitignore)
- Note: Don't edit manually; regenerate via typecheck script

**`node_modules/.pnpm/`:**
- Purpose: pnpm package store
- Generated: By `pnpm install`
- Committed: No

**`build/`:**
- Purpose: Production build output
- Generated: By `pnpm build`
- Committed: No
- Structure: `build/server/index.js` (SSR server), `build/client/**` (client assets)

**`.planning/codebase/`:**
- Purpose: Codebase documentation (created by `/gsd:map-codebase`)
- Generated: No (manually created)
- Committed: Yes
