## Codebase Patterns

- Package manager: pnpm
- Test framework: vitest
- React Router 7 with SSR - dynamic imports required for Node.js modules in loaders

- API routes use dynamic imports for server modules: `await import("~/utils/kanban.server")`

- Main route pattern: loader fetches data + syncs state, action handles mutations via fetcher

- Card-on-card drop for merge: use onDragOver/onDrop with stopPropagation to prevent column drop
