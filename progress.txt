## Codebase Patterns

- Package manager: pnpm
- Test framework: vitest
- Project type: React Router 7 with SSR
- E2E: playwright
- SQLite: better-sqlite3 with drizzle-orm
- DB queries: `~/db/queries.server.ts` (getAllStories, createStory, updateStory, archiveStory)
- Kanban utils: `~/utils/kanban.server.ts` wraps DB with business logic
- Native module builds: pnpm v10 ignores build scripts by default; manually build with `npm run build-release` in module dir
- File watcher: chokidar singleton in `~/utils/session-watcher.server.ts`, SSE at `/api/kanban/watch`
- Client hook: `~/hooks/useSessionWatcher.ts` for subscribing to session events
