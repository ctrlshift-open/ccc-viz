## Codebase Patterns

- Package manager: pnpm
- Test framework: vitest
- React Router 7 with SSR - dynamic imports required for Node.js modules in loaders
- CSS animations: custom keyframes in app.css, use `animate-` prefix for animation classes
- Panel pattern: fixed position + backdrop + body scroll lock + escape key handler

- Selection state pattern: useState for ID, useMemo to derive full object from state
